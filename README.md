# Rustii Broast | موقع المطعم

موقع صفحة واحدة لمطعم **Rustii Broast** (بروستد كرسبي، ساندوتشات، سماش برجر): منيو كامل، سلة طلب، وإرسال الطلب على واتساب.

A single-page, Arabic (RTL) restaurant website with a full menu, a cart, and WhatsApp ordering. No build step, no dependencies: everything is in `index.html`.

## المميزات | Features

- منيو كامل: 42 صنفًا في 7 أقسام (سندوتشات، سماش برجر، وجبات الدجاج، الاستربس، الميكس، أصناف جانبية، صوص) بالجنيه المصري.
- فلترة الأقسام بضغطة واحدة.
- سلة طلب: إضافة وإنقاص الكميات من المنيو أو من السلة، وإجمالي فوري.
- إرسال الطلب على واتساب برسالة جاهزة فيها الاسم والتليفون ونوع الطلب (توصيل أو استلام) والعنوان والملاحظات والأصناف والإجمالي. الطلب لا يُرسل تلقائيًا: العميل يضغط إرسال داخل واتساب.
- زرار اتصال مباشر.
- متجاوب مع الموبايل، ووضع داكن حسب إعداد الجهاز.
- خلفية متحركة خفيفة (تتوقف إذا كان الجهاز على تقليل الحركة).

## التعديل | Editing

كل التعديلات داخل `index.html`:

- **رقم الواتساب:** ابحث عن `wa.me/` (يظهر 3 مرات). الصيغة: كود الدولة 20 ثم الرقم بدون الصفر الأول، مثل `201023599661`.
- **رقم الاتصال:** ابحث عن `tel:` (يظهر مرتين).
- **الأصناف والأسعار:** داخل وسم `<script>` في المصفوفتين `S` (الأقسام الرئيسية) و`L` (الجانبية والصوص). شكل الصنف: `["الاسم","الوصف",السعر]` أو `["الاسم","الوصف",[["سنجل",95],["دابل",155]]]` للأحجام المتعددة.
- **الألوان:** متغيرات CSS في أول وسم `<style>` (`--accent` و`--btn` و`--hero` و`--gold` وغيرها).
- **صور الأقسام:** مضمنة كبيانات base64 في الكائن `IMG` داخل السكريبت. لاستبدال صورة، حوّل الصورة الجديدة (يفضل 560×560) إلى base64 وضعها مكان القديمة بنفس المفتاح.

بعد أي تعديل افتح الصفحة وجرّب إضافة صنف وإرسال طلب تجريبي، وراجع الرسالة قبل الضغط على إرسال في واتساب.

## التشغيل محليًا | Run locally

افتح `index.html` في المتصفح مباشرة، أو:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. خطوط Google Fonts تحتاج اتصالًا بالإنترنت، وبدونه يستخدم المتصفح خطوطًا بديلة.

## النشر على GitHub Pages | Deploy

1. ارفع `index.html` و`README.md` إلى مستودع **Public**.
2. من **Settings ثم Pages**: Source = **Deploy from a branch**، الفرع `main`، المجلد `/ (root)`، ثم Save.
3. بعد دقيقة أو اثنتين يظهر رابط الموقع في نفس الصفحة.

لدومين خاص: من نفس الصفحة اكتب الدومين في **Custom domain** وأضف السجلات التي تطلبها GitHub عند مسجّل الدومين.

## ملاحظات | Notes

- لا يوجد خادم أو قاعدة بيانات: الطلبات تصل عبر واتساب فقط ولا تُحفظ على الموقع.
